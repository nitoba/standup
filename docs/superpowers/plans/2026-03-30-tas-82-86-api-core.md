# TAS-82 to TAS-86 API/Core Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the API/core improvements from TAS-82 through TAS-86 with minimal, production-safe changes.

**Architecture:** Keep the current monolith structure. Reuse existing shared auth and health abstractions where they fit, add narrow helpers only where necessary, and externalize prompt content without introducing a new prompt engine.

**Tech Stack:** Turbo, NestJS 11, Hono adapter, Drizzle ORM, Better Auth, discord.js, TypeScript strict.
